This is a dotnet tool package to use AngouriMath from F# from console.

Run `amcli` for the terminal, or `amcli simp "sin(x)^2 + cos(x)^2"` to answer one command and
exit; `amcli help` lists the commands. `amcli mcp` serves the library to an agent over the Model
Context Protocol.
